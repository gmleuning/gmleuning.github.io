KoLexicon

Chrome extension for en.dict.naver.comen.dict.naver.com용 Chrome 확장 프로그램

A Chrome extension that takes over the search pages of en.dict.naver.com and shows your own layout: definitions on the left, example sentences on the right.

  • Definitions from KRDict, Naver and Wiktionary, followed by etymology: the KRDict word type, the Wiktionary etymology and, for Sino-Korean words, a hanja box with a gloss for each character that opens the Naver 한자사전 and Wiktionary entries
  • Example sentences from Naver, Weverse subtitles and Tatoeba, deduplicated and sorted by length or source, with filters and "Load more" paging
  • English searches show Naver's English headwords, Korean equivalents and matching KRDict entries
  • Layout blocks can be dragged between columns, hidden behind a button or turned off; fonts come from Google Fonts; the KRDict definitions need your own free API key
  • Naver has no public dictionary API, so the extension reads Naver's own search pages in hidden frames

en.dict.naver.com의 검색 페이지를 가져와 직접 구성한 배치로 보여 주는 Chrome 확장 프로그램입니다. 왼쪽에는 뜻풀이, 오른쪽에는 예문이 나옵니다.

  • KRDict, 네이버, 위키낱말사전의 뜻풀이에 이어 어원이 나옵니다. KRDict의 어휘 유형, 위키낱말사전의 어원, 한자어의 경우 글자마다 짧은 풀이가 붙은 한자 상자가 있고, 글자를 누르면 네이버 한자사전과 위키낱말사전 항목이 열립니다
  • 네이버, 위버스 자막, Tatoeba의 예문을 중복 없이 모아 길이나 출처순으로 정렬하며, 필터와 ‘더 보기’ 기능이 있습니다
  • 영어로 검색하면 네이버의 영어 표제어, 한국어 대응어, 일치하는 KRDict 항목이 나옵니다
  • 배치 블록은 열 사이로 끌어 옮기거나, 버튼 뒤에 숨기거나, 끌 수 있습니다. 글꼴은 Google Fonts에서 고르며, KRDict 뜻풀이에는 본인의 무료 API 키가 필요합니다
  • 네이버에는 공개 사전 API가 없어, 숨겨진 프레임에서 네이버의 검색 페이지를 읽어 옵니다

Dictat

Chrome extension for en.wiktionary.orgen.wiktionary.org용 Chrome 확장 프로그램

A Chrome extension (Manifest V3) that turns en.wiktionary.org entry pages into a single quiet reading column.

  • Contents, collapsible language sections and categories in one box; pronunciation as audio players only, with a Forvo search link when a section has no audio
  • Etymology chains ("From … from …") become a timeline, with Related, Doublet and Cognates rows; translations fold into one disclosure per part of speech
  • Chinese, Japanese and Korean get character boxes, per-language fonts and inline term lists; missing Hangul pages and Hangul searches with no exact match go to Naver
  • An "Original" button shows the page as Wiktionary renders it; settings follow your Chrome profile

Source on GitHubGitHub 소스 →

en.wiktionary.org의 표제어 페이지를 하나의 조용한 읽기 단으로 바꿔 주는 Chrome 확장 프로그램(Manifest V3)입니다.

  • 목차, 접을 수 있는 언어별 섹션, 분류를 한 상자에 모읍니다. 발음은 오디오 플레이어만 보여 주며, 오디오가 없는 섹션에는 Forvo 검색 링크가 나옵니다
  • 어원 사슬(“From … from …”)은 타임라인이 되고 Related, Doublet, Cognates 줄이 붙습니다. 번역은 품사마다 하나씩 펼침 칸으로 접힙니다
  • 중국어, 일본어, 한국어는 글자 상자, 언어별 글꼴, 인라인 용어 목록을 갖추고, 없는 한글 표제어 페이지와 정확히 일치하는 결과가 없는 한글 검색은 네이버로 연결됩니다
  • “Original” 버튼으로 위키낱말사전이 원래 보여 주는 모습을 볼 수 있고, 설정은 Chrome 프로필을 따라갑니다

Library Reader

Obsidian plugin for PDF librariesPDF 서재를 위한 Obsidian 플러그인

An Obsidian plugin that turns a vault full of PDFs into a reading room: find a book from the keyboard, read it in Obsidian's PDF viewer, and write notes beside it that open again with the book next time.

  • A Reference desk front page with the newest books, recently opened ones, a list of requests and the latest annotations
  • A Library panel built from the file list, reading authors and titles from file names, so thousands of PDFs load quickly
  • Search through the text of one book or the whole library
  • A "Needs fixing" list for scans with no text layer, oversized files, missing authors and PDFs that won't open, exportable as a checklist
  • Desktop only, plain JavaScript, no build step and no dependencies

PDF로 가득한 보관함을 열람실로 바꿔 주는 Obsidian 플러그인입니다. 키보드로 책을 찾아 Obsidian의 PDF 뷰어로 읽고, 옆에 메모를 쓰면 다음에 책을 열 때 메모도 함께 열립니다.

  • 새로 들어온 책, 최근에 연 책, 구할 책 목록, 최근 주석을 모은 ‘참고 데스크’ 첫 화면
  • 파일 목록으로 만드는 서재 패널. 파일 이름에서 저자와 제목을 읽어 PDF 수천 권도 빠르게 불러옵니다
  • 한 권 또는 서재 전체의 본문 검색
  • 텍스트 층이 없는 스캔본, 너무 큰 파일, 저자 누락, 열리지 않는 PDF를 모은 ‘손볼 책’ 목록과 체크리스트 내보내기
  • 데스크톱 전용이며, 빌드 과정과 의존성 없이 순수 JavaScript로 되어 있습니다

Koding

Korean study plugin for ObsidianObsidian용 한국어 학습 플러그인

An Obsidian plugin for studying Korean, built around one activity: making a short voice note for someone who will hear it. Everything it makes lives as ordinary notes and audio files in your vault.

  • A Desk with one large button, the next action, worked out from your files; no streaks, due counts or backlogs
  • Draft in Korean, get corrected by a person or an AI, then hear a native-voice model at normal and slow speed
  • A shadow player that plays a sentence, pauses for you to repeat it and moves on; a recorder for takes; local Whisper marks where what it heard differs from your text
  • Editable tutor prompts, AI tabs inside Obsidian, short cloze quizzes and an archive of finished notes
  • Desktop only; runs edge-tts, ffmpeg and Whisper locally

Source on GitHubGitHub 소스 →

듣는 사람이 있는 짧은 음성 메모 만들기, 이 한 가지 활동을 중심으로 한 Obsidian용 한국어 학습 플러그인입니다. 만든 것은 모두 보관함 안의 평범한 노트와 오디오 파일로 남습니다.

  • 파일을 보고 다음 할 일을 알아서 정해 주는 큰 버튼 하나의 ‘데스크’. 연속 기록, 복습 횟수, 밀린 일은 없습니다
  • 한국어로 직접 쓰고, 사람이나 AI에게 고침을 받은 뒤, 보통 속도와 느린 속도의 원어민 목소리 모델을 듣습니다
  • 한 문장씩 들려주고 따라 말할 틈을 주는 섀도잉 플레이어, 녹음기, 들은 내용과 쓴 글이 다른 곳을 표시해 주는 로컬 Whisper
  • 고칠 수 있는 튜터 프롬프트, Obsidian 안의 AI 탭, 짧은 빈칸 퀴즈, 완성한 노트 보관함
  • 데스크톱 전용이며 edge-tts, ffmpeg, Whisper를 로컬에서 실행합니다

Ujier

Chrome extension for Google ImagesGoogle 이미지용 Chrome 확장 프로그램

A Chrome extension that fixes Google Images and builds the advanced search into the results page.

  • A real size filter, by default over 2 MP, with a strict mode that reads the true pixel size of every result and drops the ones Google's own filter lets through
  • A badge on each result with its pixels, megapixels, aspect ratio and file size, colour-coded by size
  • Removes the Save buttons and clutter such as suggestion chips, related-search blocks and licensing badges
  • A filter bar above the results (type, file type, colour, aspect, date, licence, sources), with curated source sets such as museums, archives and public domain collections, and blocklists for aggregators and image farms
  • Checks itself against the live page and learns new selectors when Google changes its markup; no network requests of its own, no analytics

Google 이미지의 불편한 점을 고치고 고급 검색을 결과 페이지 안에 넣어 주는 Chrome 확장 프로그램입니다.

  • 기본 200만 화소 초과의 실제 크기 필터. 엄격 모드는 모든 결과의 실제 픽셀 크기를 읽어 Google 자체 필터가 놓친 이미지를 걸러 냅니다
  • 각 결과에 픽셀, 메가픽셀, 가로세로 비율, 파일 크기를 크기별 색으로 표시하는 배지
  • 저장 버튼과 추천 칩, 관련 검색 블록, 라이선스 배지 같은 군더더기를 제거합니다
  • 결과 위의 필터 막대(유형, 파일 형식, 색, 비율, 날짜, 라이선스, 출처), 박물관·기록물·퍼블릭 도메인 등 엄선한 출처 모음, 모아 올리기 사이트와 이미지 양산 사이트 차단 목록
  • 실제 페이지에 맞춰 스스로 점검하고 Google이 마크업을 바꾸면 새 선택자를 학습합니다. 자체 네트워크 요청이나 분석 도구는 없습니다
