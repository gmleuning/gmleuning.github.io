Beolingus Reboot

German–English dictionary search page독일어–영어 사전 검색 페이지

A single-page German–English dictionary in the look of the old BEOLINGUS site (dict.tu-chemnitz.de). It runs in the browser with no server, searching the BEOLINGUS word list from a file kept beside the page.

  • Searches German and English at once and ranks the results: exact entries first, then whole words, words that begin with the search term, and words that contain it
  • Filter results by nouns, verbs, adjectives, adverbs or other; umlaut buttons (ä ö ü); hover over the gender, register and subject tags, such as {f}, [coll.] or [med.], to read what they mean
  • Click any word in a result to look it up; every search has its own address, so the Back button and bookmarks work; `/` jumps to the search box and Esc clears it

The word list is the BEOLINGUS / Ding data (Frank Richter, TU Chemnitz, GNU General Public License), included in the repository under the same licence.

예전 BEOLINGUS 사이트(dict.tu-chemnitz.de)의 모습을 본뜬 단일 페이지 독일어–영어 사전입니다. 서버 없이 브라우저에서 작동하며, 페이지 옆에 둔 파일에서 BEOLINGUS 단어 목록을 검색합니다.

  • 독일어와 영어를 동시에 검색하고 결과에 순위를 매깁니다: 정확히 일치하는 항목이 먼저, 그다음 온전한 단어, 검색어로 시작하는 단어, 검색어를 포함하는 단어 순
  • 결과를 명사, 동사, 형용사, 부사, 기타로 거를 수 있고, 움라우트 버튼(ä ö ü)이 있으며, {f}, [coll.], [med.] 같은 성·어체·분야 표시 위에 마우스를 올리면 뜻이 나옵니다
  • 결과 속 단어를 누르면 바로 그 단어를 찾아 봅니다. 검색마다 고유한 주소가 있어 뒤로 가기와 북마크가 작동하고. `/`는 검색창으로 이동하고 Esc는 검색어를 지웁니다

단어 목록은 BEOLINGUS / Ding 데이터(Frank Richter, TU Chemnitz, GNU General Public License)이며, 같은 라이선스로 저장소에 포함되어 있습니다.

New Wiktionary

Chrome extension for en.wiktionary.orgen.wiktionary.org용 Chrome 확장 프로그램

A Chrome extension (Manifest V3) that turns en.wiktionary.org entry pages into a single quiet reading column.

  • Contents, collapsible language sections and categories in one box; pronunciation as audio players only, with a Forvo search link when a section has no audio
  • Etymology chains ("From … from …") become a timeline, with Related, Doublet and Cognates rows; translations fold into one disclosure per part of speech
  • Chinese, Japanese and Korean get character boxes, per-language fonts and inline term lists; missing Hangul pages and Hangul searches with no exact match go to Naver
  • An "Original" button shows the page as Wiktionary renders it; settings follow your Chrome profile

en.wiktionary.org의 표제어 페이지를 하나의 조용한 읽기 단으로 바꿔 주는 Chrome 확장 프로그램(Manifest V3)입니다.

  • 목차, 접을 수 있는 언어별 섹션, 분류를 한 상자에 모읍니다. 발음은 오디오 플레이어만 보여 주며, 오디오가 없는 섹션에는 Forvo 검색 링크가 나옵니다
  • 어원 사슬(“From … from …”)은 타임라인이 되고 Related, Doublet, Cognates 줄이 붙습니다. 번역은 품사마다 하나씩 펼침 칸으로 접힙니다
  • 중국어, 일본어, 한국어는 글자 상자, 언어별 글꼴, 인라인 용어 목록을 갖추고, 없는 한글 표제어 페이지와 정확히 일치하는 결과가 없는 한글 검색은 네이버로 연결됩니다
  • “Original” 버튼으로 위키낱말사전이 원래 보여 주는 모습을 볼 수 있고, 설정은 Chrome 프로필을 따라갑니다

Rogetta

Roget's Thesaurus (1911), as a single web page단일 웹 페이지로 만든 로제 시소러스(1911)

A single-file, zero-dependency web interface to Roget's Thesaurus of English Words and Phrases (1911 edition), from Project Gutenberg, with the full corpus of 1,000 entries embedded in the page. No build, server or network calls: open the file in a browser and it works.

  • Full-corpus search with headword matches first; whole-word or partial matching, with accents folded
  • Entry numbers are addresses: typing `494` opens entry 494, and results and cross-references are links that can be bookmarked
  • Roget's `&c 197` cross-references are live links, obsolete terms are marked †, and each entry keeps its path through Roget's hierarchy
  • Keyboard shortcuts, light and dark themes, and a recipe for a Chrome address-bar shortcut

프로젝트 구텐베르크의 Roget's Thesaurus of English Words and Phrases(1911년판)를 위한, 의존성 없는 단일 파일 웹 인터페이스입니다. 1,000개 표제어 전체가 페이지 안에 들어 있습니다. 빌드도 서버도 네트워크 호출도 없이, 파일을 브라우저에서 열면 바로 작동합니다.

  • 전체 말뭉치 검색에서 표제어 일치가 먼저 나오며, 온전한 단어 또는 부분 일치로 찾을 수 있고 악센트는 구별하지 않습니다
  • 항목 번호가 곧 주소입니다. `494`를 입력하면 494번 항목이 열리고, 결과와 상호 참조는 북마크할 수 있는 링크입니다
  • 로제의 `&c 197` 상호 참조는 살아 있는 링크이고, 쓰이지 않는 말에는 †가 붙으며, 각 항목은 로제 체계 속 위치를 그대로 보여 줍니다
  • 키보드 단축키, 밝은 테마와 어두운 테마, 그리고 Chrome 주소창 단축키 설정 방법
