KoLexicon

Chrome extension for en.dict.naver.comen.dict.naver.com용 Chrome 확장 프로그램

A Chrome extension that takes over the search pages of en.dict.naver.com and shows your own layout: definitions on the left, example sentences on the right.

  • Definitions from KRDict, Naver and Wiktionary, followed by etymology: the KRDict word type, the Wiktionary etymology and, for Sino-Korean words, a hanja box with a gloss for each character that opens the Naver 한자사전 and Wiktionary entries
  • Example sentences from Naver, Weverse subtitles and Tatoeba, deduplicated and sorted by length or source, with filters and "Load more" paging
  • English searches show Naver's English headwords, Korean equivalents and matching KRDict entries
  • Layout blocks can be dragged between columns, hidden behind a button or turned off; fonts come from Google Fonts; the KRDict definitions need your own free API key
  • Naver has no public dictionary API, so the extension reads Naver's own search pages in hidden frames

en.dict.naver.com의 검색 페이지를 가져와 직접 구성한 배치로 보여 주는 Chrome 확장 프로그램입니다. 왼쪽에는 뜻풀이, 오른쪽에는 예문이 나옵니다.

  • KRDict, 네이버, 위키낱말사전의 뜻풀이에 이어 어원이 나옵니다. KRDict의 어휘 유형, 위키낱말사전의 어원, 한자어의 경우 글자마다 짧은 풀이가 붙은 한자 상자가 있고, 글자를 누르면 네이버 한자사전과 위키낱말사전 항목이 열립니다
  • 네이버, 위버스 자막, Tatoeba의 예문을 중복 없이 모아 길이나 출처순으로 정렬하며, 필터와 ‘더 보기’ 기능이 있습니다
  • 영어로 검색하면 네이버의 영어 표제어, 한국어 대응어, 일치하는 KRDict 항목이 나옵니다
  • 배치 블록은 열 사이로 끌어 옮기거나, 버튼 뒤에 숨기거나, 끌 수 있습니다. 글꼴은 Google Fonts에서 고르며, KRDict 뜻풀이에는 본인의 무료 API 키가 필요합니다
  • 네이버에는 공개 사전 API가 없어, 숨겨진 프레임에서 네이버의 검색 페이지를 읽어 옵니다

Dictat

Chrome extension for en.wiktionary.orgen.wiktionary.org용 Chrome 확장 프로그램

A Chrome extension (Manifest V3) that turns en.wiktionary.org entry pages into a single quiet reading column.

  • Contents, collapsible language sections and categories in one box; pronunciation as audio players only, with a Forvo search link when a section has no audio
  • Etymology chains ("From … from …") become a timeline, with Related, Doublet and Cognates rows; translations fold into one disclosure per part of speech
  • Chinese, Japanese and Korean get character boxes, per-language fonts and inline term lists; missing Hangul pages and Hangul searches with no exact match go to Naver
  • An "Original" button shows the page as Wiktionary renders it; settings follow your Chrome profile

en.wiktionary.org의 표제어 페이지를 하나의 조용한 읽기 단으로 바꿔 주는 Chrome 확장 프로그램(Manifest V3)입니다.

  • 목차, 접을 수 있는 언어별 섹션, 분류를 한 상자에 모읍니다. 발음은 오디오 플레이어만 보여 주며, 오디오가 없는 섹션에는 Forvo 검색 링크가 나옵니다
  • 어원 사슬(“From … from …”)은 타임라인이 되고 Related, Doublet, Cognates 줄이 붙습니다. 번역은 품사마다 하나씩 펼침 칸으로 접힙니다
  • 중국어, 일본어, 한국어는 글자 상자, 언어별 글꼴, 인라인 용어 목록을 갖추고, 없는 한글 표제어 페이지와 정확히 일치하는 결과가 없는 한글 검색은 네이버로 연결됩니다
  • “Original” 버튼으로 위키낱말사전이 원래 보여 주는 모습을 볼 수 있고, 설정은 Chrome 프로필을 따라갑니다
