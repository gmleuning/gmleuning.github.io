Roget's Thesaurus (1911), as a web page웹 페이지로 만든 로제 시소러스(1911)

Open RogettaRogetta 열기 →

A web page for reading and searching Roget's Thesaurus of English Words and Phrases (1911 edition), from Project Gutenberg. All 1,000 entries are in the page itself, so it opens at once and keeps working offline.

  • Search the whole thesaurus, with headword matches first; whole-word or partial matching, with accents folded, so naive finds naïve
  • Entry numbers are addresses: typing ‘494’ opens entry 494, and results and cross-references are links that can be bookmarked
  • Roget's ‘&c 197’ cross-references are live links, obsolete terms are marked †, and each entry keeps its path through Roget's hierarchy
  • Keyboard shortcuts and light and dark themes; the page can also be set up as an address-bar search in Chrome, so typing ‘rog taciturn’ opens the results

프로젝트 구텐베르크의 Roget's Thesaurus of English Words and Phrases(1911년판)를 읽고 검색하는 웹 페이지입니다. 1,000개 항목 전체가 페이지 안에 들어 있어 바로 열리고, 오프라인에서도 작동합니다.

  • 시소러스 전체를 검색하며 표제어 일치가 먼저 나옵니다. 온전한 단어 또는 부분 일치로 찾을 수 있고 악센트는 구별하지 않아 naive로 naïve를 찾습니다
  • 항목 번호가 곧 주소입니다. ‘494’를 입력하면 494번 항목이 열리고, 결과와 상호 참조는 북마크할 수 있는 링크입니다
  • 로제의 ‘&c 197’ 상호 참조는 살아 있는 링크이고, 쓰이지 않는 말에는 †가 붙으며, 각 항목은 로제 체계 속 위치를 그대로 보여 줍니다
  • 키보드 단축키, 밝은 테마와 어두운 테마. Chrome 주소창 검색으로 설정하면 ‘rog taciturn’을 입력해 바로 결과를 열 수 있습니다
