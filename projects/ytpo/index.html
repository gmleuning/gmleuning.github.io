A font browser for Windows (pronounced "typo")Windows용 글꼴 브라우저 ("typo"로 읽음)

A minimal, local-first font browser for rapid visual inspection, custom tagging, and plaintext portability. It previews installed fonts and local font files with live custom text, and filters them by classification and your own tags.

  • Characters a font doesn't have are greyed out, so you can see at a glance which fonts really support a given script or symbol
  • Group split families (Franklin Gothic Book, Demi Cond, Heavy… as one card), rename families inside the font files with automatic backups, and archive fonts with a verified copy
  • Tags, hidden fonts and classifications are stored as human-readable Markdown, which can be exported or linked for live two-way sync, for example inside an Obsidian vault or a Git repository
  • A small Windows desktop app: a Rust backend (Tauri) around a plain HTML/CSS/JS interface

빠른 시각적 확인, 사용자 지정 태그, 일반 텍스트 이식성에 초점을 둔 최소한의 로컬 우선 글꼴 브라우저입니다. 설치된 글꼴과 로컬 글꼴 파일을 원하는 문구로 미리 보고, 분류와 직접 만든 태그로 걸러 볼 수 있습니다.

  • 글꼴에 없는 문자는 흐리게 표시되어, 어떤 글꼴이 특정 문자나 기호를 실제로 지원하는지 한눈에 알 수 있습니다
  • 나뉘어 등록된 글꼴 패밀리(Franklin Gothic Book, Demi Cond, Heavy…)를 카드 하나로 묶고, 글꼴 파일 안의 패밀리 이름을 자동 백업과 함께 바꾸며, 복사본을 검증한 뒤 글꼴을 보관할 수 있습니다
  • 태그, 숨긴 글꼴, 분류는 사람이 읽을 수 있는 Markdown으로 저장되며, 내보내거나 연결해 실시간 양방향 동기화할 수 있습니다(예: Obsidian 보관함이나 Git 저장소 안에서)
  • 일반 HTML/CSS/JS 인터페이스를 Rust 백엔드(Tauri)가 감싼 작은 Windows 데스크톱 앱
